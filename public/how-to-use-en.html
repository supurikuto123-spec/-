How to Use Guide

Sutemeado is a simple temporary email service that requires no registration and can be accessed anytime with a password. This guide provides step-by-step instructions for first-time users.

1
Access the Site

Open your browser (Chrome, Safari, Edge, etc.) and go to sutemeado.com. A new temporary email address will be generated automatically when you access the site.

Tip: You can use it from any device - smartphone, tablet, or PC. Use your preferred device.
2
Copy the Email Address

Copy the "Your Address" displayed at the top of the screen (e.g., xxxxxx@sutemeado.com). Click the copy button (📋 icon) to easily copy it.

Important: Be sure to save your password! Both the email address and password are required to access the same address again.
3
Enter the Email Address

Paste the copied address into the "Email Address" field of the service or form you want to try. Use this address for services where you want to receive confirmation emails or verification codes.

4
Wait for Email

It may take a few seconds to a few minutes for emails to arrive from the sender. Sutemeado automatically refreshes the inbox approximately every 5 seconds, so just keep the screen open and emails will appear automatically.

In a hurry: Click the "Refresh" button to immediately check for the latest status.
5
Open the Email

Click on an email in the inbox to view its contents. Check the verification code or link and perform the necessary actions.

Note: Temporary email is not for long-term storage. Always copy or take a screenshot of important information.

Useful Features

Password Protection
Each email address has a unique password. Even if you change browsers, you can access your email from anywhere with the email address and password.
Auto Refresh
The inbox automatically refreshes approximately every 5 seconds. Check new emails in real-time without manually reloading.
One-Click Copy
Email addresses and passwords can be easily copied with one click of the copy button. Prevents typing errors.
Password Change
You can change your password anytime. You can also change to a stronger password to improve security.
Delete Emails
Unnecessary emails can be deleted individually. You can also empty the inbox at once with the "Delete All Emails" feature.
Create New Address
You can create a new email address anytime. You can also add new addresses without deleting old ones.

API Usage

Sutemeado provides an API for developers and testers. Automate tests and streamline development work by operating temporary email addresses from your programs.

// Create a new address curl https://sutemeado.com/api/new-address // Login and get email list curl -X POST https://sutemeado.com/api/login \ -H "Content-Type: application/json" \ -d '{"address":"xxx@sutemeado.com","password":"xxx"}'

For details, please check the "API" menu on the top page.

How to Use the Menu

Click the hamburger menu (three-line icon) at the top right of the screen to access various features:

  • Login: Access existing address with password
  • Create New Email Address: Issue a new address
  • Delete All Emails: Empty the inbox
  • Delete Address: Delete this address itself
  • API Docs: Check detailed API specifications
  • Settings: Switch theme (Light/Dark)
  • Status: Check service operational status
  • News: Latest news and announcements
  • FAQ: Check detailed FAQ
